## Ambiguity Flags

- **""react to new issues on the repositories" does not name the repositories"**
  - Suggestion: Default to jgwill/miadi-orchestration-kit plus the repo that holds packages/miadi/deb, listed in the feedback-channel config
- **""inside of the action one a way to actually report" could mean printing a bundle or filing the issue"**
  - Suggestion: Have miadi-config report print the bundle and open a prefilled issue URL, with gh issue create when gh is authenticated
- **"Minor versus major or risky has no stated threshold"**
  - Suggestion: Minor: docs, packaging metadata, dependency pins, scripts with no data or security effect. Major or risky: security, data loss, breaking change, apt repository signing, anything touching shared infra
- **""ship a patch" for a deb package can mean commit, rebuild, or publish to the apt repository the outside developer pulls from"**
  - Suggestion: Treat commit, version bump, rebuild and apt publish as the minor ship path, and escalate when the apt publish step fails or changes signing
- **""short time, like for the next 2 weeks or something" gives no exact expiry or end behaviour"**
  - Suggestion: Expire on 2026-11-12, stop the timer, and post a summary of handled issues to Guillaume
- **""maybe replying to issues" leaves open whether replies post automatically to a human audience"**
  - Suggestion: Post replies to plain factual questions automatically and send drafts for opinion, roadmap or commitment questions as decision cards
- **""a decision engine or something" and Episode 564's readiness are unknown"**
  - Suggestion: Read Episode 564 first and fall back to a small rule table (task class to model) in the config if its engine is not usable yet
- **""might be feedback as well on the musical part" is hedged"**
  - Suggestion: Include music as a feedback type in the template and config now, with no separate seat behaviour
- **""modulable for future feedback" does not define the unit of modularity"**
  - Suggestion: One config file per feedback channel, installed and removed by a script, read by the same watcher
- **"A5 ceremony path timing is left open"**
  - Suggestion: Hold A5 until the two-week window closes and its summary exists
