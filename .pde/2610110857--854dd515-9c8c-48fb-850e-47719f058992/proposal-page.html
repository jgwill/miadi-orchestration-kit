What the evidence says about two notes

C stands for correction: a note whose claim the source does not support as written.

C1

Haiku 5.5 is 40x cheaper than Opus 5.5 only under 100K tokens per request

The T1 note says 40x "when bellow 1M tokens context". Haiku 5.5 costs $0.10 / $0.50 per million tokens up to 100K prompt tokens and $0.50 / $2.50 above. Opus 5.5 costs $4 / $20 at any length. So the ratio is 40x under 100K and 8x above. An inventory run that reads a whole transcript crosses 100K. One that reads the @miadi/hooks-interpreter digest stays under it (EP3).
