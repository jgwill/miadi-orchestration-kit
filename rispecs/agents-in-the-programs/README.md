# agents-in-the-programs

> An agent works in Kdenlive (then Ardour and MuseScore) on the person's own display while the person
> watches: it finds the episode's projects, opens one, shows it, plays it, walks its guides and checks the
> sound, saves or reloads only when asked, and proposes changes as new files. Every act is logged, improvised
> acts included, so they become the next verb. The kit lists every capability it holds in `.miadi/`.

Born from one afternoon. On 2026-11-25 a seat opened and played, on Guillaume's screen, a proposal timeline
he had never seen because the computer crashed the day before, with ten shell commands nobody had packaged.
He asked that those acts become capabilities of the factory: specified, built, inventoried.
