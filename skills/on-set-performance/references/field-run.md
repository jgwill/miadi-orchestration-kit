# Field-run acceptance ledger

## Before

- [ ] Capture intention names episode, scene, purpose and refusal boundary.
- [ ] Consent keeper and custodian are present by reference.
- [ ] Current devices fill one `field-kit.yaml` profile.
- [ ] Equipment, battery/power, storage, clock, ports and offline state are read back.
- [ ] Existing start/stop paths and recovery steps are proven.
- [ ] One shared slate event reaches each active channel.

## During

- [ ] `started` receipt exists before recording.
- [ ] Raw media stays device-local or in ignored capture storage.
- [ ] Monitoring watches channels, power, storage, clock and consent indicator.
- [ ] Interruption becomes partial/failed evidence, not a hidden correction.

## After

- [ ] Every referred artifact has a local sha256.
- [ ] Requested and observed rates remain separate.
- [ ] Signed clock drift and per-channel state are recorded.
- [ ] Duplicate event replay returns one latest receipt.
- [ ] Traversal, embedded media/words, secrets and host paths are refused.
- [ ] Git diff contains no media, credentials, participant words or participant names.

## Three human judgments

| Judgment | Keeper | Result |
|---|---|---|
| Consent/custody | participant or delegated keeper | accept / refuse / hold |
| Technical reliability | independent evaluator | reliable / conditional / unreliable |
| Artistic usefulness | creator/composer; editor for placement | accept / refuse / hold |

## Pilot completion

T10 remains a pilot until all are present:

- one verified expressive take;
- one linked composition;
- one timeline placement;
- one recorded human decision;
- one replayable receipt;
- one T3 creator-experience/narrative-beat record;
- one T1 continuation handoff that does not require the originating session.
